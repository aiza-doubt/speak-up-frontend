# Speak Up - website (deploy on Vercel)

Files in this repository: index.html, openai-adapter.js, config.js, vercel.json, README.md

Before deploying, open config.js and put your Render backend address in it, e.g.
  window.SPEAKUP_API = "https://speak-up-api.onrender.com";

Vercel settings: Framework Preset "Other", no build command, no output directory.
